ODrive CAN Protocol Command IDs. 

Defines the CAN message command identifiers for the ODrive CANSimple protocol. The CAN message ID is constructed as\+: (node\+\_\+id \texorpdfstring{$<$}{<}\texorpdfstring{$<$}{<} 5) \texorpdfstring{$\vert$}{|} cmd\+\_\+id

Messages prefixed with "{}\+Get\+\_\+"{} can be requested by the host using RTR=1, or sent periodically by the ODrive based on configured intervals. Messages prefixed with "{}\+Set\+\_\+"{} are sent by the host to configure the ODrive.

\begin{DoxyNote}{Note}
All values are encoded in little endian 

Floats use IEEE 754 standard format 
\end{DoxyNote}
