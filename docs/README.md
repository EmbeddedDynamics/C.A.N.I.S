# Documentation

Project documentation for the C.A.N.I.S. Robotdog project. written in Typst, with API docs generated by Doxygen.

## What it does

This branch contains all written project documentation in Dutch, covering the project plan, requirements, research, test reports, and stakeholder analysis. It also includes the Doxygen configuration for generating firmware API documentation from source code comments.

Documents are written in **Typst** and compiled to PDF. A shared configuration system (`Config/`) defines team members, roles, hourly rates, the MoSCoW requirements list, and planning data. Check the README.md inside the typst/ dir for more information.

## Libraries / dependencies

- **[Typst](https://typst.app/)** — document compiler (`typst compile`)
- **[Doxygen](https://www.doxygen.nl/)** — API doc generator for C firmware source

## File structure

```
docs/
├── Doxyfile                                    # Doxygen config — points at firmware/drivers/ source
└── typst/Documenten/
    ├── Hoofddocument.typ                       # Main document — imports and assembles all subdocuments
    ├── Config/
    │   ├── GeneralConfig.typ                   # Team members, roles, hourly rates, project timeline
    │   ├── PvE_MoSCoW.typ                      # MoSCoW-prioritised requirements list
    │   ├── Planning.typ                        # Project planning data
    │   ├── Role_Calculations.typ               # Hour/cost calculations per role
    │   ├── StakeholderConfig.typ               # Stakeholder definitions
    │   └── _Imports.typ                        # Central import file for Config
    ├── Subdocumenten/
    │   ├── Plan_Van_Aanpak.typ                 # Project plan
    │   ├── Blokdiagram (Hoog over).typ         # High-level block diagram description
    │   ├── Stakeholder_analyse.typ             # Stakeholder analysis
    │   └── Samenwerkingscontract.typ           # Team collaboration agreement
    ├── Onderzoeken/
    │   ├── Literatuuronderzoek.typ             # Literature research
    │   └── Transmissie.typ                     # Transmission mechanism research
    ├── Testen/
    │   ├── testplan_capstan.typ                # Capstan drive test plan
    │   ├── testplan_Robotpoot.typ              # Robot foot test plan
    │   └── Testrapport_Robotpoot.typ           # Robot foot test report
    ├── Leerdoelen/
    │   └── Leerdoel_Daan.typ                   # Individual learning objectives
    ├── Peerreview/
    │   ├── Peerreview.typ                      # Peer review document
    │   └── Peerreview_review.typ               # Peer review feedback
    ├── Referenties/
    │   └── Transmissie.bib                     # Bibliography for transmission research
    ├── Assets/
    │   ├── ED_Logo.png                         # Embedded Dynamics logo
    │   └── NHL_logo.jpg                        # NHL Stenden logo
    └── template.typ                            # Shared document template (header, footer, styling)
```

## Building

```bash
# Compile all docs to PDF
typst compile docs/typst/Documenten/Hoofddocument.typ

# Generate firmware API docs (HTML)
doxygen docs/Doxyfile
```
